# Calculator

A simple and modern calculator built with HTML, CSS, and JavaScript. This project is a great beginner frontend project and works well as part of a portfolio or GitHub profile.

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, and division
- Decimal support
- Percentage calculation
- Clear and delete actions
- Keyboard support
- Modern responsive UI

## Run locally

1. Open the project folder.
2. Start a local web server:

```bash
python3 -m http.server 8000
```

3. Open the browser at:

```bash
http://localhost:8000
```
